# Rex Makusia — Portfolio

A responsive personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Motion.

## Getting started

Use Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Scripts

- `npm run dev` — start the local development server
- `npm run lint` — lint the project with ESLint
- `npm run build` — create a production build
- `npm start` — serve the production build

## Deployment

Run `npm run build` and deploy the generated Next.js application to any Node.js host that supports Next.js. Build and start commands are `npm run build` and `npm start`; no proprietary services are required.

## Content

Portfolio content is kept in `lib/portfolio.ts`. Update the project, focus-area, or toolkit data there as it changes. The contact link currently points to the GitHub profile associated with this repository; add a verified email address or other social profile only when one is available.
